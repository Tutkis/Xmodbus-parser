Как это работает:
  • Hex dump — каждый байт окрашен по роли (address/function/data/CRC…)
  • Color band — под hex dump, показывает структуру фрейма пропорционально количеству байт в каждом поле
  • Field labels — под band, показывает размер поля (1B/2B/6B…)
  • Field cards — детали полей с hex + decimal значениями
Интерактивность (bidirectional highlighting):
  • Hover на поле в band → подсвечиваются соответствующие байты в hex dump + карточка поля
  • Hover на байт в hex dump → подсвечивается segment в band + карточка поля
  • Click на карточку поля → подсвечивается всё: байты + segment
Преимущества:
  • Видно структуру фрейма одним взглядом — какие поля, какого размера
  • Понятно где какой байт принадлежит (особенно для TCP с MBAP)
  • Цвета помогают запомнить семантику (address=оранжевый, function=зелёный, data=жёлтый, CRC=красный)
  • Пропорциональность band показывает относительный размер полей
