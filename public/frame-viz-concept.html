Layout (3 rows stacked):
  • Row 1 — Hex bytes: каждый байт в своей ячейке, окрашен по роли. Ширина ячейки = 1 байт (равная)
  • Row 2 — Color band: пропорциональные сегменты по размеру поля (flex-grow = byte count). "Data (6 bytes)" шире "Addr"
  • Row 3 — Decimal values: вертикальный текст (90°) для ключевых значений — Addr=107, Qty=3, Regs=107·200·300. Серым — label (SLAVE, FC, ADDR…)
  • Row 4 — Info: размер поля (1B/2B/6B) + hex значение
Variable-width segments:
  • Band segments используют flex-grow: N где N = количество байт в поле
  • "Addr" (1B) → узкий, "Data" (6B) → широкий — визуально видно пропорцию
  • Decimal cells выровнены по той же сетке — значения под своими полями
Vertical text (90°):
  • Decimal значения (107, 3, 6) повернуты вертикально — экономят горизонтальное место
  • Label (ADDR, QTY, REGS) серым сверху — compact reference
  • Для длинных значений (regs=107·200·300) — текст flows вертикально
Bidirectional highlighting:
  • Hover на байт → подсвечивается segment в band + decimal cell
  • Hover на band segment → подсвечиваются байты + decimal cell
  • Hover на decimal cell → подсвечивается всё
