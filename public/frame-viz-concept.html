Что изменилось в v3:
  • CSS Grid вместо flexbox — все 4 ряда используют одну сетку grid-template-columns: repeat(N-bytes, 1fr)
  • Идеальное выравнивание — band segment шириной 2B точно совпадает с двумя hex bytes под ним
  • Горизонтальный текст для decimal значений — читается естественно, не ломается на длинных значениях
  • Каждый элемент использует grid-column: span N где N = количество байт в поле
4 ряда (stacked, идеально выровнены):
  • Row 1 — Hex bytes: каждый байт в 1 колонке, окрашен по роли
  • Row 2 — Color band: сегменты span N колонок, пропорционально размеру поля
  • Row 3 — Decimal values: горизонтальный текст, серый label + white value, только для ключевых полей
  • Row 4 — Field info: размер (1B/2B/6B) + hex значение
Bidirectional highlighting:
  • Hover на любой элемент → подсвечиваются все связанные элементы в других рядах
